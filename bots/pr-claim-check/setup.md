Prepare this machine so the claim checks can run.

- Node.js 20 or newer is installed. Confirm with `node --version`.
- `git` is installed. Confirm with `git --version`.
- buzzcut 0.3.0 or newer is installed. Confirm with `buzzcut --version`. If it is missing or older, ask the user whether to install it with `npm install -g buzzcut`, wait for their answer, then confirm again.

The GitHub CLI is optional: without it the bot still checks a description the user pastes or names. Do not require it here.

Do not check any project during setup. Preparing the machine is the whole job.
